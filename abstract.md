## Abstract

Open-source repositories hosted on GitHub are widely used by software developers, startups,
enterprises, and researchers for building modern software solutions. Before adopting an
open-source repository, it is important to evaluate its health, reliability, maintainability,
documentation quality, contributor activity, governance practices, and long-term sustainability.
However, GitHub primarily provides raw metrics such as stars, forks, issues, pull requests, and
contributors, which do not directly indicate repository health or adoption readiness. As a result,
developers and organizations often spend significant time manually analyzing repositories, leading
to time-consuming and inconsistent technology selection decisions. Recent studies on Open Source
Software (OSS) health assessment emphasize the importance of community activity, maintenance
efficiency, contributor engagement, governance, documentation quality, and sustainability in
determining the long-term viability of open-source projects.

Existing OSS health assessment approaches and platforms such as GitHub Insights, OpenSSF
Scorecard, and Libraries.io provide repository statistics, security-related assessments, or partial
health indicators, but they do not offer a unified framework that combines repository health
analysis, sustainability assessment, contributor intelligence, documentation evaluation, risk
analysis, and adoption recommendations. This creates a need for an intelligent decision-support
system that can transform raw repository metrics into meaningful insights for developers and
organizations. To address this gap, the proposed AI-Assisted Developer Decision Support and
Repository Intelligence Platform automatically analyzes public GitHub repositories using data
collected through GitHub APIs. The system evaluates commit activity, contributor participation,
pull request management, issue resolution efficiency, documentation quality, maintenance trends,
and community engagement indicators. A Repository Health Index (RHI) is generated by combining
multiple OSS health metrics into a unified assessment score. The platform further performs
sustainability and risk analysis and generates AI-assisted repository intelligence reports and
repository adoption recommendations to support technology selection decisions.

The scope of the project is limited to public GitHub repositories and focuses on repository health
assessment, sustainability evaluation, repository comparison, and developer decision support. It
does not attempt source-code correctness verification, vulnerability scanning, or software defect
prediction. The expected outcome is a research-oriented platform that converts raw repository data
into actionable repository intelligence, enabling developers and organizations to make informed,
reliable, and evidence-based open-source technology adoption decisions. Success will be evaluated
through the effectiveness of the Repository Health Index, repository comparison accuracy,
repository health assessment quality, and the usefulness of the generated recommendations.
