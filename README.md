# AI-Assisted Developer Decision Support and Repository Intelligence Platform

## Overview
This project analyzes GitHub repositories and generates repository intelligence through:

- Repository Health Index (RHI)
- Contributor Analytics
- Sustainability Analysis
- Documentation Assessment
- Risk Evaluation
- AI-Based Adoption Recommendations

## Tech Stack
Frontend: React + TypeScript + Material UI
Backend: FastAPI + Python
Database: SQLite
Analytics: Pandas, NumPy
ML: Scikit-Learn
